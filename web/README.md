# OA 文档中台前端

本目录是同源静态工作台，不依赖框架、CDN、外部字体或登录页面。FastAPI 将此目录挂载到 `/web`，首页由应用根路径提供；前端通过 `/api/v1` 调用后端接口。

入口文件为 `index.html`，页面逻辑位于 `app.js`，视觉样式位于 `styles.css`，本地 SVG 图标位于 `icons.svg`。所有接口数据都通过 DOM 文本节点显示；文档正文、日志、文件名和清理依据不会作为 HTML 执行。秘密字段只在输入时短暂存在页面内存中，不写入本地存储，也不回显已有值。

工作台包含每日概览、文档分页筛选和详情、人工审核、清理建议预览/审核/确认执行，以及系统配置、知识库与业务分类映射。自动刷新间隔为 15 秒；用户修改配置时会暂停配置刷新并在离开页面前要求保存或明确丢弃。

可用以下命令做基础语法检查：

```sh
node --check web/app.js
```

页面验收应在同源 FastAPI 服务启动后进行，并用 Chrome 109 检查导航、日期、刷新开关、分页筛选、详情抽屉、审批、清理确认和配置保存流程。没有服务端真实数据或接口失败时，页面会显示加载、空状态或错误状态，不使用固定示例指标。
